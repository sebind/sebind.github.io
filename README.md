# Dr. Sebin Devasia — Academic Portfolio

Personal academic portfolio, Digital Lab, and research blog for **Dr. Sebin Devasia**, Assistant Professor in Physics at PSG Institute of Technology and Applied Research.

- **Live Website:** [https://sebind.github.io](https://sebind.github.io)
- **Digital Lab (Seal — Quantum ESPRESSO Studio):** [https://sebind.github.io/seal4qe/](https://sebind.github.io/seal4qe/)

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Type-check with TypeScript
npm run lint

# Build production bundle (syncs index.html, 404.html, assets/, and image/ to root for GitHub Pages)
npm run build
```
